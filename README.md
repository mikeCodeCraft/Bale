# Bale AI Video Creation Platform

Bale is a modern, AI-powered video creation platform for brands, agencies, and creators. It enables users to generate Hollywood-level videos quickly and affordably, without the need for a crew, camera, or studio.

## Features

- **AI-Generated Videos**: Create product explainers, brand stories, and more using advanced AI models.
- **Script to Video Pipeline**: Go from a simple prompt to a polished video in minutes.
- **Motion Design & 3D**: Add animated logo reveals, product spins, and immersive scenes.
- **Social Content Packages**: Generate Reels, Shorts, and TikToks optimized for each platform.
- **Cutting-Edge AI**: Powered by Google Veo, Kling AI, and custom models.
- **Flexible Pricing**: Choose from Starter, Pro, or Elite plans to match your needs.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Start the development server**
   ```bash
   npm run dev
   ```
3. **Open your browser**
   Visit [http://localhost:5173](http://localhost:5173) to view the app.

## Project Structure

- `src/components/` — React components for each section (Navbar, Hero, Features, etc.)
- `src/styles/` — CSS and Tailwind styles
- `public/` — Static assets
- `index.html` — Main HTML file

## Customization

- Update content, images, and styles in the respective component files.
- Adjust pricing, features, and testimonials in `bale.jsx` or split into separate data files for scalability.

## Deployment

This project is ready for deployment on Vercel, Netlify, or any static hosting provider. See `vercel.json` for Vercel configuration.
